# RGB-CMYK-HLS

# (RGB ↔ CMYK ↔ HLS)

Приложение представляет собой интерактивный колориметрический конвертер, обеспечивающий синхронный пересчет цветов между моделями RGB, CMYK и HLS в режиме реального времени. 

---

##  Архитектура приложения

1. View (view/main_window.py) — графический интерфейс на базе библиотеки PyQt5. Отвечает за отрисовку слайдеров, полей ввода, комбобоксов и градиентов. Передает сигналы пользовательского ввода во ViewModel.
2. ViewModel (viewmodel/converter_vm.py) — координатор состояний. При изменении параметров блокирует интерфейс от зацикливания, собирает данные, передает их в модель для расчетов и обновляет зависимые элементы GUI.
3. Model (model/spaces.py, model/clipping.py) — математический базис приложения. Изолированный программный слой, выполняющий прямые и обратные координатные преобразования над числовыми векторами.

---

##  Математический базис и формулы

Для всех вычислений исходные компоненты R, G, B нормируются к диапазону от 0 до 1:
rc = R / 255
gc = G / 255
bc = B / 255

### 1. Модель RGB ↔ CMYK

#### Прямое преобразование (Полноценный GCR)
Сначала рассчитывается чистая координата черного цвета K:
K = min(1.0 - rc, 1.0 - gc, 1.0 - bc)

Если K >= 1.0 (абсолютно черный цвет), то C = 0, M = 0, Y = 0, K = 100.
Иначе расчет ведется по формулам с делением на (1 - K):
C = (1.0 - rc - K) / (1.0 - K)
M = (1.0 - gc - K) / (1.0 - K)
Y = (1.0 - bc - K) / (1.0 - K)

Итоговые параметры C, M, Y, K умножаются на 100 для перевода в проценты.

#### Обратное преобразование
R = 255 * (1.0 - C/100) * (1.0 - K/100)
G = 255 * (1.0 - M/100) * (1.0 - K/100)
B = 255 * (1.0 - Y/100) * (1.0 - K/100)

---

### 2. Модель HLS ↔ RGB

#### Прямое преобразование (RGB → HLS)
Находим экстремумы: max_c = max(rc, gc, bc), min_c = min(rc, gc, bc) и разность diff = max_c - min_c.
* Светлота (L): L = (max_c + min_c) / 2
* Насыщенность (S): Если max_c == min_c, то S = 0. Иначе:
  Если L < 0.5: S = diff / (max_c + min_c)
  Если L >= 0.5: S = diff / (2.0 - max_c - min_c)
* Тон (H в градусах): Если diff == 0, то H = 0. Иначе:
  Если max_c == rc: H = 60 * ((gc - bc) / diff) + (360 если gc < bc иначе 0)
  Если max_c == gc: H = 60 * ((bc - rc) / diff + 2.0)
  Если max_c == bc: H = 60 * ((rc - gc) / diff + 4.0)

#### Обратное преобразование
Для нормированных значений L и S определяются опорные точки M1 и M2:
Если L < 0.5: M2 = L * (1.0 + S)
Если L >= 0.5: M2 = L + S - L * S
M1 = 2.0 * L - M2

Если S == 0.0, то r = g = b = L. 
Иначе вызывается функция Value(tc, M1, M2) со смещением по фазе:
r = Value(H + 120.0, M1, M2)
g = Value(H, M1, M2)
b = Value(H - 120.0, M1, M2)

Алгоритм функции Value(tc, M1, M2):
1. Если tc < 0, то tc = tc + 360. Если tc >= 360, то tc = tc - 360.
2. Анализ сектора цветового колеса:
   Если tc < 60.0: возвращаем M1 + (M2 - M1) * tc / 60.0
   Если tc < 180.0: возвращаем M2
   Если tc < 240.0: возвращаем M1 + (M2 - M1) * (240.0 - tc) / 60.0
   Иначе: возвращаем M1

Итоговые r, g, b умножаются на 255.

### 3. Модели XYZ, Lab, Luv и Стандарты освещения

Программа поддерживает динамическую смену констант точки белого (Xn, Yn, Zn) и матриц перехода на основании выбранного стандарта CIE:
* D65: Xn = 95.047, Yn = 100.0, Zn = 108.883
* D50: Xn = 96.422, Yn = 100.0, Zn = 82.521
* E: Xn = 100.0, Yn = 100.0, Zn = 100.0

#### Прямой переход RGB → XYZ
Применяется нелинейная функция линеаризации F(x):
Если x >= 0.04045: F(x) = ((x + 0.055) / 1.055) в степени 2.4
Если x < 0.04045: F(x) = x / 12.92

Вычисляются линейные значения: rn = F(R/255) * 100, gn = F(G/255) * 100, bn = F(B/255) * 100.
Координаты XYZ получаются умножением на коэффициенты матрицы из методички:
X = M[0][0] * rn + M[0][1] * gn + M[0][2] * bn
Y = M[1][0] * rn + M[1][1] * gn + M[1][2] * bn
Z = M[2][0] * rn + M[2][1] * gn + M[2][2] * bn

#### Переход XYZ → Lab
Применяется нелинейная функция F_lab(t):
Если t >= 0.008856: F_lab(t) = t в степени (1/3)
Если t < 0.008856: F_lab(t) = 7.787 * t + 16/116

Формулы расчета координат Lab:
L = 116 * F_lab(Y / Yn) - 16
a = 500 * (F_lab(X / Xn) - F_lab(Y / Yn))
b = 200 * (F_lab(Y / Yn) - F_lab(Z / Zn))

#### Переход XYZ → Luv
Рассчитываются хроматические координаты текущего цвета (u_prime, v_prime) и точки белого (u_prime_n, v_prime_n):
u_prime = (4 * X) / (X + 15 * Y + 3 * Z)
v_prime = (9 * Y) / (X + 15 * Y + 3 * Z)

u_prime_n = (4 * Xn) / (Xn + 15 * Yn + 3 * Zn)
v_prime_n = (9 * Yn) / (Xn + 15 * Yn + 3 * Zn)

Расчет светлоты L:
Если Y/Yn >= 0.008856: L = 116 * ((Y / Yn) в степени 1/3) - 16
Если Y/Yn < 0.008856: L = 903.3 * (Y / Yn)

Итоговые параметры:
u = 13 * L * (u_prime - u_prime_n)
v = 13 * L * (v_prime - v_prime_n)

##  Обработка цветов вне охвата 

При обратной конвертации в RGB математические значения могут выйти за аппаратные пределы монитора (меньше 0 или больше 255). Программа обрабатывает это двумя методами:

1. Clipping (Отсечение): Жесткое ограничение значений. Все, что меньше 0, становится равным 0, а все, что больше 255, становится равным 255.
2. Scaling (Масштабирование): Адаптивный сдвиг и пропорциональное сжатие вектора. Если минимальное значение среди R, G, B меньше нуля, ко всем каналам прибавляется корректирующий сдвиг, убирающий минус. Если после этого максимальное значение превышает 255, то все три канала умножаются на коэффициент сжатия: scale = 255.0 / max_v.
